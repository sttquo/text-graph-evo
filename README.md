# Text Graph Evolution

Учебный Python-проект для анализа изменений текста как динамического dependency-графа.

## Идея
Пользователь вводит два предложения или две короткие версии текста:
- исходный текст;
- изменённый / переписанный текст.

Программа:
- выполняет настоящий NLP-разбор через spaCy;
- строит dependency-графы для каждого текста;
- сравнивает графы по токенам и зависимостям;
- показывает изменения в словах, связях и ролях;
- визуализирует результат.

## Структура проекта

- `app.py` — точка входа для интерфейса Streamlit.
- `requirements.txt` — зависимости проекта.
- `textgraph/` — модуль с ядром NLP и графовыми компонентами.

## Быстрый старт

### О направленности dependency-графа

В проекте dependency-графы реализованы как ориентированные графы: каждая дуга
идёт от head-token к dependent-token (head → dependent). Это отражает семантико-
синтаксическую иерархию, порождаемую парсером зависимостей: например,
"запустила → Компания (nsubj)" означает, что "запустила" — главный глагол,
а "Компания" — его подлежащее. На узлах сохраняются атрибуты `idx`, `text`,
`lemma`, `pos`, `morph`, `dep`, `head`, `is_root`. Рёбра помечаются меткой
`dep` (и `label`) для удобной визуализации.

1. Установите зависимости:
```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python -m spacy download ru_core_news_sm
```
2. Запустите приложение:
```bash
streamlit run app.py
```
